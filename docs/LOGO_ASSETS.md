# Yoru logo assets

The supplied orange ribbon logo was adapted using the built-in image generation tool.

Adaptation brief: preserve the supplied logo's orange and gold gradients, ribbon Y, crescent and cloud cutouts; remove the black background, retain transparent negative spaces, and frame the complete mark in a square with a small margin and clean edges.

- `public/yoru-logo.png`: transparent application logo.
- `public/favicon.svg`: self-contained favicon embedding the adapted PNG.
- `public/yoru-mark.svg`: compatibility asset for existing mark references.

The application uses the adapted mark in navigation, login and the cinema loading indicator. Favicon metadata includes a version parameter to refresh cached browser icons.
